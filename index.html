How it works

Direct. Your devices connect to each other with WebRTC. Files never touch this website.

The code is the key. The QR link ends in #ID.KEY. The part after # stays in your browser and is never sent anywhere. Everything is encrypted with that key (AES-256-GCM) before it leaves your device.

Finding each other. A public PeerJS server introduces the two browsers. It sees an anonymous ID and IP addresses, never your files. If a direct path is blocked, a relay passes the data along, still encrypted.

Photo details. "Remove location and camera info" cuts the hidden data (GPS, camera, date) out of JPEG and PNG files without touching the image. Other formats, like HEIC, are converted to high-quality JPEG.

Limits. Keep both pages open while sending. Files are held in memory, up to 1 GB each.

Open source. Read the code or report a problem on GitHub (MIT license).
